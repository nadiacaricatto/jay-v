Começando pelo básico: O que é HTML, porquê usar e como funciona

O que é HTML:

HTML é a sigla para HyperText Markup Languagem - em pt-BR, Linguagem de Marcação de Hipertexto.
É uma linguagem de código - e não de programação! - declarativa, ou seja, descreve a estrutura e significado do conteúdo de uma página.
Por não ser uma linguagem de programação, HTML nunca será usado para definir o que fazer com cada elemento - só vamos definir o que é cada um.

Porquê HTML:

Sem ele, o navegador eixibira um texto plano, sem qualquer hierarquia ou organização visual.
Em outras palavras: sites como conhecemos - imagens, links, formulários etc. - não existiriam.
Pensa em qualquer coisa.
Pensou?
Pois é, sem HTML não dá pra executar nada disso.

Como funciona:

HTML funciona, principalmente, com o uso de tags - ou marcadores: elas envolvem o conteúdo num abracinho e falam pro navegador "Esse conteúdo representa [qualquer coisa]".
Tags devem ser abertas < e fechadas > - e podem ter atributos ou informações adicionais.
A gente consegue montar um site inteiro com HTML então?
Sim e não.
Ele é o esqueleto do site, então a grosso modo, a gente consegue sim montar um site!
O problema é que o visual seria exatamente como você tá vendo essa página: xoxa, capenga, anêmica.
A grande limitação do HTML é que, sozinho, ele nunca vai entregar nada bonito, e muito menos comportamento dinâmico.
E é por isso que pra construir o visual e definir o que fazer a gente usa outras linguagens (CSS, TypeScript, React, JavaScript etc.).

Agora que você entendeu, vamos ver a estrutura básica de uma página HTML!

Vamos linha por linha:

Configurando a página:

#1: <!DOCTYPE html> é a primeira linha de código da página, e indica que o navegador deve renderiazar o conteúdo em HTML moderno!
Essa indicação evita que o site carregue todo torto - e mais feio ainda.

#2: <html lang = "pt-BR"> define a linguagem da página - nesse caso, português brasileiro - mas poderia ser qualquer outra.

#3: <head> é um contâiner, invisível pros usuários. Sua função não é visual, e sim informações (metadados, links para scripts, folhas de estilo etc.) sobre a página.

#4: <meta charset="UTF-8"> é um exemplo de metadado inserido dentro da tag head: ele define a forma de codificação dos caracteres.
UTF-8 é o padrão universal usado em sites, e garante que acentos e símbolos sejam exibidos da forma correta. Sem UTF-8, à viraria Ã©, ç viraria ã...
#5: <title> é a tag que define o nome - ou título - que aparece na aba do navegador para o usuário </title>

#6: E já que colocamos todas as informações que a gente queria dentro da head, é hora de fechar a tag:

<!DOCTYPE html>
                    
    <html lang="pt-BR">

        </head>
Contâiner fechado, é hora de começar a definir o <body> da página!

Definindo o conteúdo visível da página com <body>

O conteúdo visível é tudo que o usuário vai... ver.
Exemplos do que o body carrega: títulos, parágrafos, listas, divisões, rodapé, cabeçallho, menu, imagens, links, formulários...
